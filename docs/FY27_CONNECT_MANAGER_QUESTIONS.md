# FY27 Connect Metric Questions for Manager Confirmation

**Prepared:** September 23, 2026  
**Purpose:** Confirm the working definitions Sales Buddy will use for the FY27
Data Connect Goals Action Center.

The definitions below are our current working assumptions. Please confirm or
correct each one.

## 1. Milestone team coverage population

**Working definition**

Use active FY27 Data milestones due during either:

- The current Microsoft fiscal year.
- The next Microsoft fiscal year.

These milestones form the team-coverage denominator.

**Question**

Is current plus next fiscal year the correct due-date scope, and should the
population include only active milestones?

## 2. Milestone team coverage weighting

**Working definition**

Calculate team coverage using milestone ACR rather than milestone count:

`ACR on milestones where I am on the team / total ACR for all in-scope milestones`

Milestone counts may be shown as supporting context but do not determine the
official percentage.

**Question**

Is ACR weighting the official calculation? If so, which MSX ACR or milestone
value field is the authoritative weight?

## 3. HVA coverage milestone population

**Working definition**

The HVA coverage denominator is every active, on-team FY27 Data milestone due
in the current or next Microsoft fiscal year.

A milestone is covered when it has at least one qualifying HVA activity during
the current fiscal year.

**Question**

Is this the correct milestone population, and should the HVA activity itself
have to occur during the current fiscal year?

## 4. Qualifying HVA activity categories

**Working definition**

All of the following MSX task categories count as HVA:

- Assessment
- RFP/RFI
- Technical Workshop
- Workshop
- Solution Whiteboarding
- Architecture Design Session
- Demo
- L300+ Demo
- Rapid Prototyping
- PoC/Pilot
- Technical Close/Win Plan
- Blocker Escalation
- Consumption Plan

`Assessment` and `RFP/RFI` are newly included in the qualifying HVA set.
`Briefing` remains an available MSX task category but does not count as HVA.

**Question**

Does this complete list match the FY27 definition of qualifying HVA activity?

## 5. Technical-validation activity subset

**Working definition**

For the Connect technical-validation summary, report counts for:

- Technical Workshop
- Demo
- L300+ Demo
- Architecture Design Session
- PoC/Pilot

These are supporting activity counts. The Connect text does not provide a
numeric attainment target for this subset.

**Question**

Are these the correct task types for demos, workshops, architecture,
prototypes, MVPs, and pilots? Should Rapid Prototyping also be included in this
technical-validation subset?

## 6. Fabric and database whitespace wins

**Manager-confirmed definition - September 24, 2026**

The target is:

- At least one Fabric whitespace win per fiscal half.
- At least one Databases whitespace win per fiscal half.

A customer and bucket produce one sustained win when:

1. The first positive-ACR month occurs during the fiscal half.
2. The same customer and bucket had $0 ACR in each of the three complete months
   immediately before that positive month.
3. The customer and bucket remain above $0 for at least three consecutive
   months beginning with the activation month and remain above $0 through the
   latest available month.
4. The bucket is Fabric or Databases.

There is no minimum monthly ACR threshold. One or two consecutive positive
months appear as ramping progress but do not count toward the goal. An
activation that returns to $0 before or after confirmation no longer counts.

Attribute a confirmed win to the fiscal half containing its activation month.
